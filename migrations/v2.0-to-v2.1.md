## 2. 创建标准扩展占位文件

在目标项目 `.ai/` 下创建(空文件或带表头的占位):

```txt
.ai/glossary.md     # 术语表
.ai/handoff.md      # 会话交接
.ai/plans/          # 计划目录
.ai/plans/done/     # 已完成计划归档
```

builder 初始化时会自动创建;存量项目可手动创建或运行 builder 升级模式。
